## 系统概述

SlideTutor 是一个 AI 驱动的演示文稿幻灯片辅导系统，通过交互式解释、问答和测验帮助学生理解和学习演示文稿幻灯片。

**核心能力：**
- 使用多模态 AI 进行幻灯片分析和解释
- 交互式追问和回答
- 自动测验生成和评估
- 跨多张幻灯片的上下文感知学习

**设计原则：**
- **无状态**：无服务器端会话存储（兼容 Vercel Serverless）
- **安全**：多层安全防护，带 Token 认证
- **高性能**：流式响应、客户端缓存
- **可扩展**：速率限制、高效资源使用

## 技术栈

### 前端
- **框架**：React 19 + Vite
- **语言**：TypeScript
- **状态管理**：React Hooks（useState、useEffect、自定义 hooks）
- **HTTP 客户端**：Fetch API + 自定义封装（`apiClient.ts`）
- **构建工具**：Vite

### 后端
- **运行时**：Node.js
- **框架**：Express.js
- **语言**：TypeScript
- **文档分析**：Volcengine OCRPdf
- **AI 提供商**：
  - Google Gemini（主要）
  - Doubao（字节跳动）
  - Qwen（阿里巴巴）

### 基础设施
- **托管**：Vercel（Serverless Functions）
- **数据库**：better-sqlite3（本地存储）
- **邮件**：Nodemailer
- **安全**：Helmet.js、CORS、express-rate-limit
