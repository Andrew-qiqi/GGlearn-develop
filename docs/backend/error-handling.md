# 错误处理

本文档描述 GGlearn 项目的错误处理策略和横切关注点。

最后更新：2026-03-28

---

## 错误处理

### 策略
失败软着陆，提供用户友好的警告和日志记录。

### 模式

**安全守卫：**
- `api/generate.ts` 阻止未授权域名并处理速率限制

**内容审核检查：**
- 后端 `checkMaliciousIntent` 过滤越狱尝试

**中止控制器：**
- `useTutorStore.ts` 管理 `AbortController` 取消正在进行的 AI 生成

---

## 横切关注点

**日志记录**：`server.ts` 中的后端 API 日志记录跟踪 IP、方法和持续时间

**验证**：`api/generate.ts` 中的后端检查输入类型和格式

**认证**：通过域级安全守卫和存储在环境变量中的 API 密钥隐式处理
