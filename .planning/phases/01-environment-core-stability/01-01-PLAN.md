## Verification Criteria

### Automated
- `npm run test` must pass all suites (including new security and layout tests).
- `npm run build` must complete without errors.
- `npm run lint` must return no type errors.

### Manual
- **Security Check**: Build the app and run `grep -r "AI_KEY_VALUE_HERE" dist/` to ensure no environment variable leakage.
- **API Functional Check**: Verify `/api/generate` still functions correctly with a local test request after security hardening.

## Goal-Backward Verification (Must Haves)
- [ ] API keys are completely isolated from the client bundle (Vite config fix).
- [ ] Startup validation prevents the app from running in an insecure/misconfigured state.
- [ ] Regression tests cover the most fragile part of the AI pipeline (PDF layout).
- [ ] Prompts are "locked" via snapshots to prevent accidental instruction drift.
