"请结合左侧图片布局和上述 ID 标记，为学生讲解该页面的知识点。你可以引用 ID 确保定位精准，也可以基于视觉自由描述。"

为什么这是“10x”的提升？

  • 解脱（Freedom）：LLM 不再是在一堆 ID 里“找茬”，而是在看图说话。ID 只是它引用时的“快捷键”。
  • 准确（Precision）：因为 LLM 知道了 ID 的精确 BBox，它吐出的讲解会与图上的位置高度一致。
  • 连贯（Consistency）：它能理解“地标 P1 下方的留白意味着这是一个新的章节”，这种视觉暗示对教学非常重要。
