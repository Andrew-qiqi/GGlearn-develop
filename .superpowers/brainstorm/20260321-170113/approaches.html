知识点高亮：优化方案对比

目标：从“碎片化”转向“语义完整性”

1

方案 A：外接矩形合并 (Bounding Box Merge)

逻辑：将属于同一个知识点的所有小块坐标，合并为一个覆盖全区的大矩形（取 Min-Top, Min-Left, Max-Bottom, Max-Right）。

  • 实现最简单
  • 视觉干净
  • 如果包含非矩形区域（如 L 型段落），会覆盖无关内容
2

方案 B：语义 ID 锚定 (Semantic ID Anchoring)

逻辑：LLM 不再返回原始坐标，而是返回对应 Layout 块的 ID。前端根据 ID 直接获取完整的 Layout 块坐标进行高亮。

  • 坐标绝对准确
  • 完全遵循原始布局
  • LLM 负载低
  • 需要 LLM 具备极强的 ID 对应能力
3

方案 C：智能物理聚合 (Spatial Aggregation) - 推荐

逻辑：前端接收碎坐标后，进行空间计算：如果两个框在垂直方向上相邻且水平重叠度高，自动合并为一个复合路径。同时保留 LLM 的 BBox 提示。

  • 鲁棒性最强
  • 无需改变协议
  • 适应不规则形状
  • 前端计算逻辑稍复杂

我的建议：方案 B + 方案 C 的混合模式

让 LLM 尽可能返回 ID（语义锚点），如果 LLM 无法确定 ID，则回退到物理坐标。前端使用一个 BoxGroup 组件来处理这些坐标的视觉融合（通过 CSS filter: blur() 或简单的矩形并集逻辑）。

请查看 Visual Companion (http://localhost:52341) 选择你倾向的方案，或者在终端告知我你的看法。
