# GGlearn

GGlearn is an AI-powered textbook product evolving from earlier SlideTutor experiments. The current focus is not chat or slide tutoring, but a structured study workflow:

- configure AI access
- import source material
- generate a textbook outline
- expand chapters into readable content
- study through notes, handwriting, AI explanation, quizzes, and export

## Repository Layout

- `GGlearn/`: current active application workspace
- `.omx/`: execution memory, artifacts, migration logs, and acceptance reports
- `docs/`: architecture, backend, frontend, operations, and historical documentation

## Current Status

The current overnight execution focus is driving GGlearn to a verifiable MVP where the main path is usable end-to-end and the core notebook tooling exists inside the reading flow.
